Fundamentos de Programación Orientada a Objetos (POO) en Python
📌 Introducción
Este repositorio reúne las soluciones y ejercicios prácticos enfocados en dominar los pilares básicos de la Programación Orientada a Objetos con Python. A lo largo del proyecto se implementan conceptos clave como el diseño de clases, la instanciación de objetos y la protección de datos mediante encapsulamiento, culminando en un caso de estudio real para la gestión y préstamo de equipos.

🎯 Conceptos Clave Evaluados
Modelado de Clases y Objetos: Creación de plantillas y su posterior instanciación en memoria.

Métodos Constructores: Uso de __init__ para la inicialización dinámica del estado de los objetos.

Encapsulamiento y Atributos Privados: Control de acceso a la información interna mediante el uso de guiones bajos (__atributo).

Comportamiento y Métodos: Definición de funciones internas para manipular la lógica del negocio.

Manejo de Colecciones: Integración de listas y diccionarios dentro de los objetos para la persistencia de datos en memoria.
